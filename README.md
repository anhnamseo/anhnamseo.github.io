# Portfolio Nguyễn Hữu Nam Anh

Website tĩnh HTML/CSS/JavaScript, dùng được trên GitHub Pages. Mở `index.html` để xem bản cục bộ.

## Đưa lên GitHub Pages

1. Giải nén toàn bộ tệp ZIP.
2. Tải `index.html`, `style.css`, `main.js` và **cả thư mục `assets/`** lên thư mục gốc của repository `anhnamseo.github.io` (không tải riêng ZIP rồi mong GitHub tự giải nén).
3. Vào **Settings → Pages → Build and deployment**, chọn **Deploy from a branch**, nhánh `main`, thư mục `/(root)` và **Save**.
4. Mở `https://anhnamseo.github.io/` sau khi GitHub xuất bản.

Đường dẫn trong trang đều tương đối nên cũng chạy được dưới đường dẫn dự án `https://anhnamseo.github.io/<ten-repo>/`.

## Thành phần

- `index.html`: nội dung, metadata, các khối dự án và liên hệ.
- `style.css`: bố cục máy tính và điện thoại.
- `main.js`: menu di động, các tab quy trình, mở rộng ảnh, khung liên hệ.
- `assets/`: ảnh dự án gốc do bạn cung cấp, chân dung và CV PDF từ portfolio cũ.

Khung “Liên hệ nhanh” chỉ tạo email; không phải chatbot AI và không lưu dữ liệu người dùng. Nếu thay CV, giữ đúng tên `assets/cv-nguyen-huu-nam-anh.pdf` hoặc sửa liên kết trong HTML.
